# 2026-07-27 新增功能

## SystemAdapter 跨平台架构

`packages/system/src/SystemAdapter.ts`

所有 OS 差异通过 `ISystemAdapter` 接口抽象，只封装"Node.js 跨平台做不好的操作"：

| 功能 | Linux | Windows | macOS |
|------|-------|---------|-------|
| 进程查找 | `pgrep -f` | `tasklist` / PowerShell | `pgrep -f` |
| 进程终止 | `kill` (SIGTERM/SIGKILL) | `taskkill /PID` | `kill` (SIGTERM/SIGKILL) |
| 服务注册 | systemd user service | NSSM / 开机启动 | launchd agent |
| 用户数据目录 | `~/.sage` | `%APPDATA%/Sage` | `~/.sage` |

LinuxAdapter/WindowsAdapter/MacOsAdapter 三份实现，工厂自动检测 `process.platform`。

## AutoValidate — 写文件后自动验证

`src/tool/AutoValidate.ts`

`write_file`/`patch` 执行后自动触发轻量验证，结果追加到 tool result 末尾：

| 后缀 | 验证 | 超时 |
|------|------|------|
| `.ts`/`.tsx` | `npx tsc --noEmit` | 5s |
| `.json` | `JSON.parse()` | 同步 |
| `.py` | `python -c "compile(...)"` | 3s |

实现：`AgentRuntime.ts:1150` eval 循环中 `write_file`/`patch` 结果后追加。

## CronJobTool 纯 JS 定时器

重写自 `execSync("crontab -l")`（Linux only），改为 `cron` npm 包 + JSON 文件持久化：

- 任务存储：`~/.sage/data/cron-jobs.json`
- 进程重启自动恢复：`restoreCronJobs()`（Main.ts 启动时调用）
- 支持 cron 表达式和 `every Xh`/`30m` 格式
- 不依赖系统 crontab，Windows/Linux/macOS 通用
